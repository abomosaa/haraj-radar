# رادار حراج — نسخة التطبيق (بدون سيرفر)

هذا المجلد هو التطبيق كاملاً: صفحات وملفات فقط. لا يحتاج نافذة سوداء ولا Node ولا سيرفر.
البحث يتم من جهاز المستخدم مباشرة إلى حراج، والمفضلة والتنبيهات تُحفظ على جهازه.

## نشره مجاناً (مرة واحدة)

التثبيت كتطبيق يحتاج رابط https، فارفع هذا المجلد على استضافة ملفات مجانية:

**Cloudflare Pages (الأسهل):**
1. سجّل مجاناً في dash.cloudflare.com.
2. Workers & Pages ← Create ← Pages ← **Upload assets**.
3. اكتب اسماً للمشروع (مثل `haraj-radar`)، ثم اسحب مجلد `web-app` كاملاً وأفلته.
4. يعطيك رابطاً مثل `https://haraj-radar.pages.dev` — هذا رابط تطبيقك.

بديل: GitHub Pages (ارفع محتوى المجلد في مستودع ثم Settings ← Pages)، أو Netlify Drop.

## التثبيت

- **الكمبيوتر (Chrome / Edge):** افتح الرابط، ثم أيقونة التثبيت في شريط العنوان، أو زر «ثبّت التطبيق» داخل الصفحة.
- **أندرويد (Chrome):** زر «ثبّت التطبيق»، أو ⋮ ← «تثبيت التطبيق».
- **آيفون (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## التنبيهات في هذه النسخة

- تعمل والتطبيق مفتوح أو مصغّر، حسب المدة التي تختارها في «تنبيهاتي».
- إذا قُفل التطبيق تماماً يتوقف الفحص، وأول ما يُفتح يفحص ويعرض الجديد.
- على أندرويد والكمبيوتر (Chrome/Edge) قد يفحص المتصفح أحياناً والتطبيق مقفول إذا كان مثبتاً، لكن المتصفح هو من يحدد التوقيت.

## التحديث

لا تعدّل الملفات هنا مباشرة. عدّل في `express-app` ثم شغّل:

```
cd express-app
node build-web.js
```

وارفع مجلد `web-app` من جديد (Cloudflare Pages ← المشروع ← Create deployment).
