كيف تشغّلها؟

  1. هذه الصفحة تشتغل مباشرة بدون تثبيت، لكن تحتاج الـ Backend شغال عشان تجيب نتائج.
  2. شغّل الـ Backend على جهازك: uvicorn server:app --port 8000
  3. اعرض هذه الصفحة عبر سيرفر محلي: python -m http.server 5173 داخل مجلد pwa/ ثم افتح http://localhost:5173
  4. لو فتحت index.html مباشرة بدون سيرفر، البحث يشتغل عادي طالما الـ Backend شغال، لكن التثبيت يحتاج سيرفر محلي + HTTPS أو localhost.

العنوان الحالي للـ Backend مضبوط على http://localhost:8000/api/search. لو جهازك مختلف عدّله من أعلى ملف app.js.
